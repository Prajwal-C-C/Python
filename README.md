# Python Practice

Small Python exercises and practice programs.

## `second_largest.py`

Reads an array of integers from the user, then prints its second-largest
distinct value and its largest value.

Run it with:

```powershell
python second_largest.py
```

Enter the number of array elements, followed by each integer when prompted.
The input needs at least two distinct values for a second-largest value to
exist.
